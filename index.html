O que é

Um curso para publicar em escala sem SaaS pago

Site de curso estático (HTML + Tailwind), organizado em 6 trilhas. Para devs solo, agências, criadores e founders que querem publicar em escala — usando ferramentas open-source ou construindo o próprio sistema.

🚀 Caminho rápido

Suba o Postiz self-hosted com Docker e publique em mais de 30 plataformas. O atalho para quem quer resultado sem montar tudo do zero.

🚀 Conectar APIs

Aprenda a integrar X, LinkedIn, Bluesky, Instagram, WordPress, Ghost, Dev.to e Hashnode — APIs simples, sem aprovação.

🚀 Construir do zero

Seu próprio mini-Postiz em NestJS + Prisma + BullMQ: providers, fila de publicação e OAuth genérico.

Pré-requisitos

O que ter à mão

O curso é um site estático — basta um navegador. Para as trilhas práticas você usa Docker (Postiz) e Node (construir do zero).

Navegador + Git

O conteúdo é HTML estático. Clone o repositório ou apenas abra os arquivos no navegador.

# clonar e abrir
git clone https://github.com/inematds/mkblogs

Docker (Trilha 2)

Necessário para subir o Postiz self-hosted. Tenha Docker e Docker Compose instalados.

# conferir
docker -v
docker compose version

Node.js (Trilha 5)

Para construir o mini-Postiz em NestJS + Prisma + BullMQ.

# conferir
node -v
Guia de uso · passo a passo

Como percorrer o curso

As trilhas ficam em curso/trilha1..6/, cada uma com seu index.html e módulos. Siga a ordem ou pule direto para o caminho que faz sentido pra você.

1

Abrir o índice do curso

O index.html na raiz lista as 6 trilhas e o público-alvo.

npx serve .   # sobe o site estático em localhost
2

Começar pelos Fundamentos

Entre na Trilha 1 para o mapa e os conceitos antes da prática.

open curso/trilha1/index.html  # 🧭 Fundamentos
3

Escolher o caminho prático

Postiz pronto (Trilha 2) para resultado rápido, ou construir do zero (Trilha 5) se quiser controlar tudo.

open curso/trilha2/index.html  # 🐳 Postiz Self-Hosted
open curso/trilha5/index.html  # 🛠️ Construindo do Zero
4

Conectar redes e blogs

Trilha 3 cobre as redes sociais; Trilha 4, os blogs (WordPress, Ghost, Dev.to, Hashnode).

open curso/trilha3/index.html  # 🔑 Conectar Redes
open curso/trilha4/index.html  # 📝 Blogs
5

Subir para produção

Finalize com a Trilha 6 para fazer o deploy e operar.

open curso/trilha6/index.html  # 🚀 Deploy & Produção
Exemplos

Para quem é este curso

Quatro perfis que tiram proveito direto do MkBlogs.

🚀 Devs solo

Publicar em várias plataformas sem manter um SaaS pago — Postiz pronto ou seu próprio sistema.

🚀 Agências

Centralizar publicação de múltiplas contas e marcas em redes e blogs, em escala.

🚀 Criadores

Distribuir o mesmo conteúdo em X, LinkedIn, Bluesky, Instagram e blogs automaticamente.

🚀 Founders

Montar a distribuição de conteúdo da empresa sem depender de ferramenta fechada.
